Dashboard/ Network Tools

Ping Checker

Simulasi ping ke satu atau banyak host sekaligus. Hasil meliputi latency, packet loss, dan jitter.

Traceroute Simulator

Telusuri jalur routing ke host tujuan dengan simulasi hop latency per TTL.

Port Scanner

Periksa port yang terbuka pada sebuah host. Mendukung scan preset (web, database, mail) atau port kustom.

DNS Lookup

Simulasi resolusi DNS untuk berbagai tipe record: A, AAAA, MX, NS, TXT, CNAME, PTR.

SSL/TLS Certificate Checker

Periksa validitas sertifikat SSL domain, tanggal kedaluwarsa, cipher suite, dan chain trust.

WHOIS Lookup

Periksa informasi registrasi domain, pemilik, tanggal expire, dan nameserver.

Bandwidth Estimator

Hitung estimasi kebutuhan bandwidth berdasarkan jumlah pengguna, jenis layanan, dan kualitas yang diinginkan.
